## Projetos selecionados

### Portal Acode — Inteligência de produção têxtil

Plataforma de **Business Intelligence para o setor têxtil**, voltada ao acompanhamento da produção em telas de fábrica, computadores e dispositivos móveis. O projeto adota uma arquitetura modular e prevê integração com ERPs.

**Tecnologias:** .NET 8, ASP.NET Core, JavaScript, HTML, CSS e SVG. PostgreSQL e n8n fazem parte da arquitetura planejada.

**Situação:** em desenvolvimento; repositório privado.

### Hub ERP — Sistema de gestão empresarial

Projeto colaborativo de um **sistema ERP**, com foco na evolução da aplicação, organização técnica e documentação das alterações. Minha participação ocorre no contexto de desenvolvimento e colaboração.

**Situação:** projeto colaborativo em desenvolvimento.

[Repositório do projeto](https://github.com/jeffSv16/Hub_Erp)

### Cuidado Feminino — Plataforma digital de saúde

Projeto de plataforma assistencial voltada ao acompanhamento da saúde feminina, registro de sintomas, educação em saúde e organização de informações para acompanhamento clínico.

**Tecnologias documentadas:** Java, Spring Boot, React, TypeScript e banco de dados relacional.

[Repositório Full Stack](https://github.com/AntonioWandrey/cuidado-feminino-fullstack)
